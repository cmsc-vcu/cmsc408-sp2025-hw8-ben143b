## Overview
This is my assignment of Homework 8 of CMSC 408 (Databases) that involves World Bank's World Development Indicators (WDI) analysis with SQL. It was to filter, search, and manipulate country-level metadata, build summary tables, and master advanced SQL skills like conditional aggregation, cross join, and subqueries.

## Prerequisites

* Python 3.11+ installed and available on your PATH.

* Poetry for dependency and virtual environment management.

* A running MySQL (or compatible) database with the World Bank schema loaded under the world_bank_data database.

## Setup Instructions

* Install dependencies:
    poetry install

* Activate the virtual environment:
    poetry shell

Test your DB connection
